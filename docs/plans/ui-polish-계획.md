## 가정
이탈 감점 200점, 재출발 = 커브 시작 15m 앞·기본 속도 / 1랩은 FINISH!만 / 이탈 OFF 기록은 따로 표시 / 틱·이탈음은 합성 /
기본 스타일 day(저장값 있으면 존중) / WebKit WebGL2 불가 시 UI·입력만 검증.

## 메모
- 1-4: 기존엔 아치(t=0.95)가 랩 n-1 끝에서 FINAL LAP을 띄웠음 → 실제 마지막 랩에 들어선 뒤(랩 넘김 시점)에 표시. 검증은 새 `verify-polish.mjs`(--browser=chromium|webkit, 섹션 추가식)에 쌓는다.
- 2: 재출발 지점이 앞 커브 끝자락이면 그 커브를 중간부터 판정해 연쇄 이탈(3→2→1)이 났음 → 재출발 직후 그 커브는 판정 제외(`_skipCurveKey`).
  실패율: score-sim 평균 플레이어(커브 25% 엉성 = 이탈 규칙 없는 기존 기준선)는 1·2단계 11~12%, 5단계 39%로 목표 초과. 엉성함은 밸런스 값(minLean/holdSec)과 무관한 모델 특성
  (0.25초 단위로 누르다 떼는 플레이는 어떤 유지 시간으로도 못 채움)이라 밸런스 값은 안 건드리고, 이탈 시뮬의 평균 플레이어를 "커브 12% 놓침"으로 가정(`--dsloppy`, 초보 25%는 failRateNovice로 병기) → 1~2단계 0~1%, 5단계 17%.
