## 핵심 설계 결정
1. **CSS 구조**: 토큰은 `css/ui-tokens.css` 한 곳. 컴포넌트·화면 CSS는 `css/ui.css`. 모든 값은 토큰만 사용(색·그림자·반경 12/20/28/999·간격 8px 배수·모션). 3D 위 HUD는 뉴모픽 변형(불투명 크림 + 1.5px 반투명 흰 테두리 + 아래 진한 그림자 1겹).
2. **뉴모픽 눌림**: 요소 자체 box-shadow는 애니메이션하지 않고, `::after`의 inset 그림자를 opacity/transform으로 켬(눌림 90ms, scale .97). 그림자는 요소당 2겹 이하, backdrop-filter·blur 금지. low 프리셋(`html[data-q=low]`)은 그림자 1겹 + 1px 경계선.
3. **모달 팝업 컴포넌트** `UI.popup({id,title,blocks,actions})`: 블록(문단·컨트롤 행·그림)을 화면 크기에 맞춰 자동으로 페이지에 담음(측정 → 그리디 패킹, 회전·리사이즈 시 재계산). 높이 ≤ 50vh(그림자 제외), 정중앙, 폭 세로 min(88vw,420)/가로 min(70vw,560). 다 못 담으면 페이지(점 표시·이전/다음·마지막 확인). 팝업이 떠 있으면 게임 일시정지(튜토리얼 카드는 기존 hold). 전체 화면 UI(타이틀·스테이지 선택/상세·결과·로딩)는 글꼴·문구·뉴모픽만 적용.
4. **균형 바**: 입력값(−1~1) = 노브 위치. 터치는 pointerId 추적·바 밖으로 미끄러져도 유지(setPointerCapture는 try/catch). 놓으면 0.3초에 가운데로. 키보드는 누르는 동안 초당 1.2씩 천천히 변하고 노브가 따라 움직임(손으로 못 끎, `.locked`), 기울기도 같은 바에 표시. 판정(`cart._evaluateSegment`)은 그대로 `leanInput`만 사용.
5. **부스트 링**: `cart.gateTiming()` 단일 소스 유지 — 같은 err 값으로 버튼 바깥 링 반지름·Good/Perfect 띠 두께를 계산(식은 팝업과 동일, 척도만 바뀜). 중앙 팝업은 판정 글자(PERFECT!)와 라벨 용도로만 남김.
6. **점멸 안전**: Perfect 구간 동안 3Hz 이하(333ms 주기 이상)로 색상 순환 + 링 두께·크기 맥동(색 외 신호), 강한 빨강 전체 번쩍임 없음, 별 반짝임은 링 둘레의 작은 요소. reduced-motion이면 고정 무지개 테두리.
7. **폰트**: Noto Sans KR 가변 폰트를 소스에서 쓰는 글자만 서브셋한 woff2(400/500/700 한 파일), Jua(디스플레이)도 같은 방식으로 자체 호스팅 → Google Fonts 링크 제거. 폴백 체인은 요청 그대로. SW 캐시에 포함.
8. **strings.js**: 키-문구 맵 + `t(key, params)`. 설정값에서 나오는 숫자(유지 시간·바퀴 수 등)는 인자로 받음.
9. **타이틀**: SVG 로고(Jua 글리프 외곽선을 도형으로 변환) + CSS transform/opacity 애니메이션 + 2D 레이어 배경(SVG). 합계 300KB 이하.

## 타이틀 디자인 스펙 (2번 구현 전에 확정)
- **구성(위→아래)**: 하늘 그라데이션 / 햇살 광선 / 먼 구름(시차 느린 층) / 먼 언덕 2겹 / 트랙 곡선(화면을 가로지르는 S자, 지지대) + 위를 달리는 노란 카트 / 가까운 구름(빠른 층) / 로고(화면 위 1/3, 약 −4° 기울임) / "RIDE IT" 리본 / START(큰 노란) / 작은 원형 아이콘 4개(설정·조작법·튜토리얼·크레딧) / 제작사 표기.
- **색**: 하늘 #2f7de1→#9fd8ff, 햇살 흰색 8~10%, 언덕 #7fd36b·#4fbf5d(낮), 트랙 네이비 #141a33 + 노랑 점선, 카트 노랑/주황, 로고 안쪽 #FFD84D→#FF8A1F 그라데이션, 외곽선 네이비 #141a33, 두께(입체) #b4570f→네이비, 하이라이트 흰색 55%. "!!!"는 3개를 크기(1.0/1.2/1.45배)와 기울기를 달리해서 강조(빨강 #ff5a4e 안쪽).
- **그림자 규칙**: 빛은 왼쪽 위. 접촉 그림자(작고 진한 타원) + 주변 그림자(크고 옅은 타원) 두 겹, 색은 네이비 계열의 따뜻한 반투명(검정 금지). 로고·카트·버튼·구름 모두 동일.
- **애니메이션**: 입장 — "떨"→"어"→"진"→"다"→"!!!" 순서로 위에서 낙하(0.5초 간격 70ms 스태거), 착지 시 찌그러짐(scaleY .82/scaleX 1.12)→늘어남→안착, 착지 먼지 3개, 화면 흔들림 2px·120ms(타이틀 컨테이너 transform). 이후 로고 둥실(translateY ±4px, 3.2초), 구름 시차 이동(40/70초), 카트 트랙 위 주행(SVG 모션 패스 또는 transform), 속도선 6개. 전부 transform/opacity만. low는 속도선·반짝임 제거, reduced-motion은 정적.
- **용량**: 타이틀 전용 에셋(SVG·CSS·글리프 경로) 합계 300KB 이하, 첫 화면 1초 이내.
- **시안**: A(둥실 로고 + 풍경 중심) / B(속도 강조: 기울어진 큰 로고 + 속도선·역동 트랙) / C(배지형: 원형 엠블럼 + 로고) 중 비교, 선택 이유를 개발기록에 기록.

## 가정
- START 버튼은 스테이지 선택으로 이동(AGENTS의 메뉴 흐름 유지), 설정·조작법·튜토리얼·크레딧은 타이틀의 작은 원형 버튼에서도 열림(설정 화면 내용은 그대로).
- 주행 HUD의 스테이지 이름 칩은 최소화 원칙에 따라 제거(일시정지 팝업에 이름 표시), 바퀴/커브 표시는 한 칩으로 합침.
- 부스트 타이밍 링이 버튼 바깥으로 옮겨지므로 중앙 큰 팝업은 판정 글자 전용(링 척도는 버튼 크기에 맞춰 축소).
- 키보드 균형: 누르는 동안 초당 1.2씩 변화, 놓으면 0.3초에 복귀. 바 터치는 손가락 위치에 노브가 거의 즉시(20/초 추종) 따라감.
- 모달 페이지 높이: 가로(높이 375)에서는 패널 최대 187px이라 글을 3~4줄씩 나눔. 설정은 컨트롤 행 단위 페이지.
- "확인창"은 현재 게임에 없음(일시정지→스테이지 선택은 바로 이동) — 분류표에 "해당 없음"으로 기록, 새로 만들지 않음.
