# 타이틀 화면 디자인 스펙 (2차 UI 개선 2번)

계획서(`docs/plans/ui-polish-2-계획.md`)의 스펙을 구현 단위로 풀어 쓴 문서. 구현 전에 확정하고, 시안 비교 후 선택 결과는 개발기록에 남긴다.

## 목표
- 밝고 따뜻한 상용 캐주얼 게임 타이틀. 브랜드 색 옐로 `#FFB80D` · 네이비 `#141a33`. 다른 게임의 로고를 모사하지 않는 독창적 구성.
- 첫 화면이 1초 안에 보이고(START가 바로 눌림), 타이틀 전용 에셋 합계 300KB 이하.
- 세로 375×667 · 가로 667×375 · 데스크톱 1280×720에서 중앙 정렬과 안전 영역이 깔끔.

## 구성 (위 → 아래, 세로 기준)
1. **하늘**: 그라데이션 `#2f7de1 → #62b3f5 → #bfe4ff`(지평선 쪽으로 옅어짐) + 천천히 도는 햇살 광선(흰색 8%).
2. **먼 구름**(느린 층) · **먼 언덕**(`#8fd67a`) · **가까운 언덕**(`#5fc25a`).
3. **트랙 곡선**: 화면을 가로지르는 S자 언덕 곡선(네이비 레일 + 노랑 점선, 지지대) 위를 **노란/주황 카트**가 달림.
4. **가까운 구름**(빠른 층), 속도선 몇 줄.
5. **로고** "떨어진다!!!": 화면 위쪽 1/3, 약 −4° 기울임. **"RIDE IT"** 네이비 리본.
6. **START**(가장 큰 버튼) → **작은 원형 아이콘 4개**(설정·조작법·연습 코스·크레딧, 크림 패널 안, 각각 14px 라벨) → 제작사 표기.
- 크기 위계: 로고 > START > 아이콘 버튼.
- 가로 화면: 왼쪽에 로고, 오른쪽에 START + 아이콘 패널(그리드 2열), 데스크톱은 가운데 정렬 최대 폭.

## 로고
- Jua 글리프 외곽선을 SVG path로 변환(`tools/make-logo.py` → `js/title-logo-data.js`) — 폰트 로딩과 무관, 어떤 배율에서도 선명.
- 글자마다 4겹: ① 두께 실루엣(네이비, 오른쪽 아래) ② 두께 면(`#B4570F`) ③ 앞면(안쪽 `#FFD84D → #FF8A1F` 그라데이션, 굵은 네이비 외곽선) ④ 윗면 광택(흰색 60% → 투명, 위 45%).
- 글자별로 위치·기울기를 조금씩 달리해(±3°, 상하 ±3%) 통통 튀는 느낌. "!!!"는 크기 1.0 / 1.2 / 1.45배 · 안쪽 색 빨강 `#FF8A7A → #E5362B`.
- 빛은 왼쪽 위 고정(두께·그림자는 오른쪽 아래).

## 그림자 규칙
- 접촉 그림자(작고 진한 타원) + 주변 그림자(크고 옅은 타원) 두 겹, 색은 네이비 계열 반투명(검정 금지), 오른쪽 아래로 치우침.
- 로고·카트·버튼·구름(아랫면 푸른 음영) 모두 같은 규칙. `text-shadow` 번짐 금지.

## 애니메이션 (transform / opacity만)
| 시점 | 내용 |
|---|---|
| 0.2초~ | 글자 7개가 위에서 하나씩(간격 110ms) **떨어져** 착지: 찌그러짐(가로 1.12·세로 .82) → 늘어남 → 안착, 착지 순간 먼지 3개 |
| 마지막 착지 | 화면 흔들림 2px·120ms(타이틀 전체 translate) |
| 0.6초~ | "RIDE IT" 리본이 아래에서 올라오며 등장, START·아이콘 패널 페이드 인(눌림은 바로 가능) |
| 이후 계속 | 로고 둥실(translateY ±4px, 3.2초), 구름 시차 이동(70초/40초), 카트가 트랙 위를 한 바퀴(8초), 햇살 천천히 회전(90초), 속도선 |
- `prefers-reduced-motion`: 전부 정지, 완성된 구성만 표시. low 프리셋: 햇살·속도선·반짝임 제거, 구름만 이동.

## 버튼
- **START**: accent-raised(노랑), 아래쪽 두께(주황 그림자), 윗면 광택 띠, 눌리면 3px 내려감(::after inset), 남색 글자 24px, 폭 min(72vw, 300px) · 높이 64px.
- **아이콘 4개**: 크림 패널(raised-md) 안의 원형 버튼 52px(raised-sm) + 아래 14px 라벨, 눌림은 ::after inset.

## 시안 (비교 후 하나 선택)
- **A 풍경형**: 위 구성 그대로(풍경 + 달리는 카트, 로고 −4°).
- **B 속도형**: 로고를 더 크게 −8° 기울이고, 트랙을 대각선(왼쪽 아래→오른쪽 위)으로 세워 카트가 치고 올라가는 구도, 흰 사선 속도선 8줄.
- **C 배지형**: 큰 크림 원형 엠블럼(햇살 무늬가 천천히 회전) 안에 로고, 아래에 작은 언덕과 카트, 색종이 별.
- 선택 기준: 글자 선명도(2x/3x), 위계, 대비, 그림자 일관성, 정렬, 애니메이션 부드러움, 첫 화면 표시 시간, 용량. 선택한 시안은 최대 3회 개선.

## 검증
- 세로·가로·데스크톱 스크린샷, 용량(≤300KB), 첫 화면(START 표시)까지 시간, 애니메이션이 transform/opacity만 쓰는지(`getAnimations` 키프레임 속성 검사), reduced-motion 정적 구성.
