## 동작과 맞춘 곳 (설명이 코드와 달랐던 것)
1. **키보드 출발**: 예전 "↓ 충전, ↑ 발사"는 맞지만 "↑ 놓기"로 쓴 곳이 있었음 → "↓ 꾹 누르고 ↑"(↑를 누르면 발사).
2. **시점 버튼**: 예전 설명은 "시점 전환"만 있었으나 실제로는 반대 시점을 `MANUAL_VIEW_SEC`초(6초) 동안만 보여 주고 설정값으로 돌아옴 → 시간을 코드 값으로 받아 표기.
3. **기록 "플레이 N회"**: 저장되는 횟수는 완주 횟수(`ProgressManager.record`는 완주 때만 호출) → "N번 완주".
4. **유지 시간 "1.5초"**: 문구에 직접 쓰면 3단계(1.2초)·5단계(0.9초)와 어긋남 → `{hold}`로 스테이지 값(`balance.holdSec`)을 받음, 조작법은 "0.9~1.5초" 범위를 코드에서 계산.
5. **탈선 설명**: 설정에서 끌 수 있고 튜토리얼에는 없다는 점을 조작법·연습 코스에 명시.
6. **그래픽 화질 설명**: 낮음 = 그림자·흐림 효과 끔(`shadows: none`, `radialBlur: 0`), 높음 = 실시간 그림자·모션/방사형 블러(`shadows: realtime`, `motionBlur`) — 코드(`QUALITY_PRESETS`)와 일치함을 확인.
7. **뒤로 미끄러짐**: 1단계는 부스터가 자동으로 쏘아 올리고(`auto`), 4단계·연습 코스는 BOOST 연타(`mash`) → 조작법은 둘 다 포함, 단계 상세는 모드별로 다른 문장.
