# 용어집 — 화면에 쓰는 말 (UI 문구 기준)

화면 글자는 모두 `js/strings.js`에서 관리하고, 이 표의 말만 쓴다. 금지어 검사: `node .claude/skills/run-ride-it/check-wording.mjs`
(개발 문서·코드 주석·변수 이름은 예전 말을 써도 되지만, 사용자에게 보이는 글에는 "쓰지 않는 말"을 넣지 않는다.)

## 게임 용어
| 쓰는 말 | 뜻 (처음 나올 때 한 줄 풀이) | 쓰지 않는 말 |
|---|---|---|
| 가속 지점 | 레일 위 노란 표시. 여기서 부스트를 눌러요 | 게이트 |
| 균형 잡기 | 커브에서 바를 끌어 손잡이를 초록 띠 안에 두는 일 | 밸런스, 밸런스 게이지 |
| 손잡이 | 균형 바 위의 둥근 조절 부분(노란 링) | 노브, 커서 |
| 부스트 | 속도를 확 올려 주는 가속 — "부스트(가속)"으로 한 번 풀이 | (BOOST는 버튼 글자로만) |
| 탈선 | 커브를 놓쳐 레일 밖으로 나가는 일. 하트가 줄어요 | 이탈, 레일 이탈 |
| 커브 | 굽은 구간 | 턴 |
| 바퀴 | 코스를 한 번 도는 것 | 랩, LAP |
| 결승선 | 바퀴의 끝이자 완주 지점(아치) | 피니쉬, 피니시, FINISH |
| 완주 | 마지막 바퀴의 결승선을 지나는 것 | 클리어 |
| 단계 | 1~5단계 코스 | 스테이지 |
| 연습 코스 | 처음 해 보는 조작 연습(꼬마 열차 연습장) | 튜토리얼 |
| 등급 | S·A·B·C — 얼마나 잘했는지 | 랭크 |
| 점수 | 기록 숫자 | 스코어 |
| 콤보 | 연속으로 잘했을 때 쌓이는 점수 보너스 — "콤보(연속 성공)"으로 풀이 | |
| 연타 | 버튼을 마구 누르는 것 | |
| 뒤로 미끄러짐 | 언덕에서 카트가 뒤로 밀리는 구간 | 뒤로 떨어지기 |
| 도움 가속 | 속도가 너무 느려질 때 카트가 알아서 밀어 주는 것 | 부스터 보조 추진, 부스터 타이어 |
| 하트 | 남은 기회(탈선하면 하나씩 줄어요) | |
| 바 | 균형 바 / 스타트 바 | 게이지, 슬라이더 |
| 링 | BOOST 버튼 둘레에서 줄어드는 동그란 띠 | 타이밍 팝업 |

## 판정 말
화면에는 **PERFECT · GOOD · MISS**로 표시한다(게임에서 흔한 표현). 설명 글에서는 한 번 풀이한다:
PERFECT(완벽) · GOOD(좋음) · MISS(아쉬움).

## 설정·그래픽 용어
| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 화질 | 낮음·보통·높음 — 폰이 느리면 낮춰요 | 품질, 프리셋 |
| 화면 스타일 | 카툰 낮 · 카툰 노을 · 파스텔 · 사실적 | 스타일 프리셋, 렌더링 |
| 소리 | 켜짐·꺼짐 | 사운드, ON/OFF, 토글 |
| 시점 | 3인칭(카트를 뒤에서 봐요) · 1인칭(카트 안에서 봐요) | 카메라, FOV |
| 균형 조작 | 바 끌기 / 기울기 | 입력 방식 |

## 쓰기 규칙
- 해요체로 통일, 한 문장에 한 가지 내용, 40자 안팎(가로 폰 팝업은 한두 문장씩).
- 어려운 한자어·영어 약어 지양. 영어는 버튼 글자(BOOST, START)·판정(PERFECT/GOOD/MISS)·SCORE·NEW 정도만.
- 유지 시간, 하트 수, 바퀴 수, 시점 전환 시간처럼 설정값에서 나오는 숫자는 문구에 직접 쓰지 말고 `{hold}`·`{hearts}`·`{sec}`로 코드 값을 받는다(유지 시간은 스테이지마다 다름).
- 단계 이름(우방타워랜드 등 실제 놀이공원 이름)은 그대로 쓰고, 소개 글만 쉬운 말로 쓴다.
