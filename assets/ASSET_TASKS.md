# ASSET_TASKS.md — Cowork 작업 브리프

이 폴더(`assets/`)를 Cowork에 연결할 때, 아래 내용을 작업 목표로 전달하세요.
Cowork는 세션 간 기억이 유지되지 않으므로, 매번 이 파일을 먼저 읽게 하거나
프롬프트에 이 파일 경로를 언급하는 것을 권장합니다.

## 폴더 역할
- `models/` — Blender에서 익스포트한 .glb 파일 (카트, 트랙 지지대, 배경 오브젝트)
- `textures/` — 모델에 사용되는 텍스처 이미지

## 반복 작업 정의

### 1. 텍스처 최적화
새 텍스처 파일이 `textures/`에 추가되면:
- 해상도가 2048px를 넘으면 2048px로 리사이즈 (품질 프리셋 `high` 기준 상한)
- PNG는 손실 없는 범위에서 용량 압축, JPG는 품질 85 기준으로 재인코딩
- 파일명은 `역할_해상도.확장자` 형식으로 통일 (예: `rail_metal_1024.jpg`)

### 2. glTF 파일 검증
새 `.glb`가 추가되면:
- 파일 용량이 2MB를 넘는 개별 모델은 표시하고 보고 (SE2 초기 로딩 목표: 전체 에셋 5MB 이내)
- 텍스처가 파일 내부에 임베드되어 있는지 확인 (외부 참조 방식이면 경고)

### 3. NAS 백업 동기화
- `blender/` 폴더(.blend 원본)는 매 작업 세션 종료 시 NAS의 지정 백업 경로로 복사
- 배포용 `assets/`와 원본용 `blender/`는 분리 유지 — `blender/`는 절대 GitHub에 커밋하지 않음 (`.gitignore` 처리됨)

### 4. 파일 목록 리포트
요청 시, 현재 `models/`, `textures/` 안의 파일 목록과 각 용량을 정리해서 보고
(전체 에셋 용량이 5MB 목표치에 가까워지는지 추적하기 위함)

## 하지 말아야 할 것
- `js/` 폴더의 코드는 건드리지 않음 (코드 로직 변경은 Claude Code 쪽 담당)
- `stages.js`의 제어점 좌표는 이 브리프 범위 밖 — 트랙 형태 변경은 별도 논의 필요
